# 重启人格图鉴（H5 传播版 v4）

面向 **失业 / 被裁 / 转行 / 长期空窗 / 应届未就业** 的 H5 性格与职业方向测评。17 道题、16 型人格、8 大类 × 180 个 L3 岗位（火锅店服务员、甜品店员、咖啡师、快递驿站、月嫂、CNC、焊工、水电工、无人机飞手等），支持具体城市多选与本地薪资修正。静态站 + Vercel Serverless，作答默认只存本机。

## 人群与题库（v4）

- **身份阶段**：应届/零经验、长期空窗、刚离职、在职看机会、状态模糊
- **个人约束**：经济容错、收入底线（3k 起）、可投入时间、健康体力、工作形态、启动资金
- **城市粒度**：Q15 选 1–5 个具体城市；按城市能级修正薪资，并按本地产业标签加权
- **自营倾向**：可识别“想支个摊/开小店”的用户，对 `self` 岗位加分、对启动资金不足做降权
- **零经验友好**：无经验/学生时技能重合与行业迁移不做惩罚，`entry` 岗位加分
- **报告文案**：应届走“经历改写”，空窗走“空窗期叙事”，有工作经验走常规简历改写

## 计分引擎口径

- 17 题 → 6 维原始分 → 按各维满分归一化到 0–100（`AXES_MAX`，改题务必同步上限）
- 16 型识别 = 四组二值判别（外向/内向 × 分析/直觉 × 驱动/支撑 × 守序/灵活）
- 岗位池：按 `JOBS[].arcs` 的多原型权重取候选，不再单原型硬隔离
- 硬过滤：学历 / 健康体力；收入、形态、年龄转为软惩罚，保证三条路线都有候选
- 六维软打分：技能重合 / 行业迁移 / 性格延续 / 市场时机 / 投入可行 / 城市匹配
- 三条路线：**稳健**（先站稳、现金流为正）/ **成长**（能积累、越做越值钱）/ **上限**（高薪或自营），每条都输出 2–3 条具体推荐理由
- 结果卡展示 L4 具体岗位：`城市 · 门店/企业类型 · L3 岗位`，薪资按城市能级修正
- 三枚二次指标（试错胆量/续航/紧迫度）为趣味口径，非科学量表，结果页已标注

## 部署到 Vercel

CLI：

```bash
npm i -g vercel
vercel            # 首次，自动关联账号
vercel --prod     # 上线 production
```

面板：vercel.com → Import `career-reboot` 目录 → Deploy。

- **缓存纪律**：改动 js/css 后，把 index.html 里全部 `?v=N` 参数 +1 再部署。
  Vercel/CDN 会缓存静态资源、浏览器也会吃旧文件——曾因用户测到修复前的
  旧版 data.js 白屏而返工，版本号是强制刷新的唯一手段。

**绑自有域名**：Deploy 页 Domain → Add → 输入你的域名 → 按提示把 DNS 的
`CNAME` 指向 `cname.vercel-dns.com`（根域用 A 记录指 `76.76.21.21`）。

## 静态图鉴（SEO / 低维护）

`npm run build:guide` 会从 `js/jobs.js`、`js/cities.js` 生成：

- `/guide/` 索引页
- `/guide/jobs/*.html`：180 个岗位页
- `/guide/cities/*.html`：40 个重点城市页
- `/guide/questions/*.html`：12 个转行问题页
- `sitemap.xml` / `robots.txt`

这些页面是纯静态 HTML，不依赖前端 JS；样式在 `css/guide.css`。数据更新后重跑一次即可，之后只需每月检查一次。`vercel.json` 已把 `/guide/` 排除在 SPA rewrite 之外，并给静态页设置 1 小时缓存。

## 微信里分享的三件事（上线前必做）

1. **og:image**：微信抓链接卡片需要一张常驻静态图。把海报样式导出成
   `og-card.png` 放到项目根目录（index.html 已引用 `/og-card.png`）。
   内容与各型无关，做一张通用版即可。
2. **二维码**：海报二维码走 `api.qrserver.com`（公网服务，已内置失败降级）。
   若要彻底离线，把 `poster.js` 的 `loadQR()` 换成本地 qrcode 库即可。
3. **中文域名/短链**：海外二维码服务对长链支持良好，无需短链；保持
   `location.href` 原样生成即可。

## 扩展题库的守则

- `QUESTIONS[].opts[]`：`add.dims` 的键必须命中 `AXES` 的 key（`analytic/maker/creative/social/leader/stable`），否则该维度永远为 0
- `ARCHETYPES[].combo` 同理；组合型写两个轴 key，别写错拼写（曾有 `analyst/analytic` 一字之差导致双高型全灭的事故，以此校验为准）
- `JOBS[]`：每条 L3 必须有 `tasks(≥5) / req / skills / arcs / tr / salRange / orgs / learn / week1`；同一个岗位允许 `arcs` 多原型归属
- 改完岗位或城市数据后跑自检：`npm run test:data`（校验 180 岗、8 大类分布、16 型每型 ≥20 个候选、城市字段）
- 参与人数不再展示虚构数字；如需展示，必须接入真实埋点并标注口径

## 合规红线（已内置，勿删改）

- 全部页面标注「趣味性格探索，不构成医疗、心理诊断或就业承诺」
- 不收集手机号、不要求登录、不做诱导分享；作答默认只存本机，仅 AI 摘要发送匿名画像
- 职业薪资为公开报告量级参考，免责写在页面底部；健康题可跳过
