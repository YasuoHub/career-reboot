## 三 使用建议

1. **生图模型**：Midjourney v6 / DALL-E 3 / Flux Dev 对这套二次元矢量响应良好；SDXL 需额外 LoRA 才能稳定出扁平矢量风。
2. **批量生产**：每张单独 channel 跑，避免风格漂移；如需更写实降 `--s` 到 500，更风格化升到 900。
3. **文件命名**：
   ```
   /avatars/01-hunter-f.png   /avatars/01-hunter-m.png
   /avatars/02-pioneer-f.png  /avatars/02-pioneer-m.png
   ...
   /avatars/16-explorer-f.png /avatars/16-explorer-m.png
   ```
4. **接入方式**：见下方"落地配套"。
