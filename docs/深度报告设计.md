## 二 逐屏内容设计

### §0 顶部封面（4 行）
- 「**猎手 · The Hunter**」大字，跟结果页同款视觉延续，强化一致性
- 副标：基于你在 2026-11-XX 的作答生成（时间戳——制造"专属感"，也留证据）
- 稀有度彩蛋：「你这种重启者仅占 8%」（跟结果页 rarity 字段同源）

### §1 你是谁（内容重心）

#### A. 三段式人格解读
模板骨架（三段各 80~120 字，可分型定制）：
```
① 你是什么样的人（刻画）
   → 从 archetype.cn / slogan / keywords 派生，但不要直接复述，加一句场景化的画面感描写

② 为什么是这样（成因）
   → 从该型的 D1×D2×D3×D4 四元判别反推：你的能量来源偏外向+分析驱动，
      所以你做事方式是...
   （这个解释让用户觉得"它真的看懂我"）

③ 这种人的隐藏优势（赋能）
   → 不是吹捧，是给一个"你没意识到但其实是优势"的观察
   → 例：解题人"能把混乱拆成步骤的能力，在任何岗位都是救火队资源"
```

#### B. 六维详细解读
每维 80~120 字，三层信息：
```
你现在的得分：X/100（对应雷达图的位置）
高分意味什么：这个维度的描述词 3~5 个
你的实际表现：跟你 profile 里的其他数据结合（比如你选了"沟通销售"+"Excel"，
             你的 social 得 40%，意味着你在销售场景发挥一般，
             但 excel 场景下会爆发——这类个体化观察最让用户觉得"懂我"）
```

**关键技巧**：同一维在不同 profile 下给出不同解读（比如 age=18~24 和 age=46+，同分 social 说成"青春资本充足"和"阅历型资本"）。

#### C. 同型代表人物（虚构但真实感）
每型准备 3 个虚构案例，覆盖不同行业/年龄段/性别：
```
@90 年上海某 SaaS 公司 CSM · 离职 3 个月
  现在在做：独立帮助中小企业搭建客户成功体系
  转型路径：5 年 CSM → 独立顾问
  她的原话（虚构访谈）："把混乱变有序这件事，我越做越上瘾。"
```
- **作用**：给被测者一个"跟我一样的人真的这么走了"的参照系，降低转型焦虑
- **风险控制**：虚构必须足够真实但不冒充真实从业者（合规边界），报告里标注"案例为示意性场景，非真实人物"

#### D. 与其他型协作关系
一张小矩阵：
```
跟 X 型合伙 → 互补（X 能补你的短板）
跟 Y 型冲突 → 注意（Y 的能量方向跟你不同，会踩到你雷区）
跟 Z 型师徒 → 最顺畅（Z 是你的天赋放大器）
```
这一节同时是**双人对比报告的伏笔**（后面裂变机制要用）

### §2 你可以做什么（TOP3 方向展开）

每个方向的结构固定为 7 块：

| # | 元素 | 说明 |
|---|---|---|
| ① | 方向钩子 | 一句话/15 字内能勾起好奇的表达，不是"前端工程师"这种死板名称 |
| ② | 为什么适合你 | 用用户的 archetype + industry + skills 数据挂钩，**不是泛泛的"适合你"**。例：`你的社交=40%、分析=70%、制造业前行业迁移度=0.5`，所以"售后工程师"比"大客户销售"更适合——把 scoreNum 背后的 fb 拉出来给人看 |
| ③ | **12 周入门路径** | 每周一行；内容要**受 profile.hours 影响**（在职 5 小时 vs 全职 30 小时路径措辞完全不同）|
| ④ | 必备技能清单 | 从 ACTIONS[].req.skills 展开，每个技能给学习渠道+时长+费用区间 |
| ⑤ | **简历改写模板** | 用户没上传简历也没关系——给一段示范：他现在简历里可以怎么改（比如他原本写"负责订单管理"→改写成"搭建了从采购到发货的全链路订单 SOP，减少 X% 周转天数"）。**引用 q11.industry + q13.skills 关键词** |
| ⑥ | 面试高频问题 + 参考答案 | 3-5 道题，针对 archetype 定制。比如"猎手型：讲一次你搞定最难客户的经历"、"解题人：你怎么拆解一个不熟悉的业务问题" |
| ⑦ | 已有的 badge（国家新职业/绿色职业）+ 月薪展示 | 从 ACTIONS 数据带过来，作为信任背书 |

**关键差异化技巧**：
- TOP3 本来就由打分引擎按 profile 排出来的，每人天然不同
- 12 周路径注入 hours（`≤5h/周` vs `全职`）→ 措辞不同：前者"拆成 4 个月慢节奏"，后者"集中 3 个月拿下"
- 简历改写段落注入 industry + skills 具体词——同是"猎手型"，IT 前和制造前需要两份不同的改写示例

### §3 立刻能动手的三件事（更深层版）
现有轻版只给"列 20 个熟人清单"这一级——深度版要更进一步：
```
本周 → 别只是列清单，约一位前同事线下聊聊，了解 3 条可迁移经验
本月 → 把上一份工作里一个完整的项目，从头到尾写成 SOP 文档
下月 → 按 §2.TOP1.③ 的第 3 周节点，完成对应里程碑
```
每件事带一句"为什么这一步重要"的注解。

### §4 我的重启画像卡（可保存·可转发）
升级现有 Canvas 海报，加更多维度+更强的视觉张力：
- 六维雷达图换成可视化条形图（比雷达更易传播辨识度）
- 加一个"优势关键词云"（从 keywords 抽出来，字号越大代表越突出）
- 加一句"60 秒测出你"作为 QR 下方的钩子（方便新用户被好友的海报吸引来测）
- 这张卡的视觉风格要跟海报统一，形成品牌识别

## 四 分型差异化策略

三种差异化层次并行，避免机械重复：

| 层次 | 做法 |
|---|---|
| **数据驱动**（每人不同）| top3 排序、skills 交集、12 周路径的 hours 变体 |
| **型模板**（16 型各一份）| §1.A 三段解读、§1.D 协作矩阵、§2.⑥ 面试问题 |
| **型变体的参数**（同型不同 profile 微调）| §1.B 六维解读的措辞层、§2.⑤ 简历改写段落 |

**优先级**：先把 16 型 × §1.A 各写一份（约 16×250 字=4000 字，可控）；其余部分用参数注入避免重复劳动。
