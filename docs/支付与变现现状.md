# 支付与变现现状（2026-11-25）

> 本文是当前实际实施的方案。历史文档 [支付宝 AI 付 / Vibe Pay](./支付宝AI付-VibePay接入.md) 与 [微信支付](./微信支付接入.md) 已不再对应线上实现，仅作备选方案参考。

## 一、支付通道

- 产品：**支付宝手机网站支付**（`alipay.trade.wap.pay`，`product_code=QUICK_WAP_WAY`）
- 应用与产品已签约上线，站点：`https://www.career-turn.icu`
- 价格：服务端唯一来源 `ALIPAY_PRICE`（默认 `9.90`），前端展示由 `/api/alipay/price` 获取，前端传价格无效
- 回调：`notify_url = {ALIPAY_SITE_URL}/api/alipay/notify`，`return_url = {ALIPAY_SITE_URL}/api/alipay/return`
- 微信内置浏览器无法唤起支付宝，前端会提示“在浏览器打开”。

## 二、订单与解锁（无状态设计）

Vercel Serverless 多实例不共享内存，因此**不持久化订单**，以支付宝侧订单为唯一权威：

1. `POST /api/alipay/create-order` → 生成 `outTradeNo`，返回签名后的收银台 URL。
2. 用户支付完成 → 支付宝 302 到 `/api/alipay/return` → 再 302 回 `/?pay_return=1&out_trade_no=...`。
3. 前端调 `POST /api/alipay/verify` → 服务端 `alipay.trade.query` 主动查单，校验金额/卖家/订单号。
4. 支付成功 → 服务端签发 HMAC 解锁令牌（90 天）→ 前端存 localStorage → 打开深度报告。
5. 若回跳失败或用户提前关页，再点一次解锁会先核上一笔订单（30 分钟内），避免重复付款。

`/api/alipay/notify` 仅做验签 + 订单号格式 + 金额校验，作为日志与兜底；业务解锁不依赖它。

## 三、深度报告权益

- 权益凭证：`rb_unlock = { token, exp, via }`，`via ∈ pay | share`
- 令牌由服务端私钥派生密钥签名，前端无法伪造
- 清除浏览器数据/换设备会丢失本机凭证；付费用户可凭订单号联系售后核验
- 报告在本机根据作答数据生成，不上传服务器

## 四、邀请裂变（可选，需配置存储）

规则：邀请 3 位好友完成测评，可免费解锁同一份深度报告。

- `GET /api/invite/state?uid=` → `{ configured, progress, need, unlocked, token? }`
- `POST /api/invite/claim { ref, viewer, archetype }` → 好友完成测评后上报
- 服务端存储：Upstash Redis（Vercel Marketplace 一键创建），环境变量：
  - `KV_REST_API_URL` / `KV_REST_API_TOKEN`，或
  - `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`
- 未配置时接口返回 `configured:false`，前端自动隐藏邀请卡片，付费链路不受影响。
- 防刷：`ref != viewer`；同一 viewer 终身只计 1 次；邀请关系 90 天过期。
- 已知限制：无账号体系，无法完全防脚本伪造“新好友”。对 9.9 元产品可接受，后续接入登录可收紧。

## 五、AI 个性化摘要（可选）

- `POST /api/ai-summary`，只发送人格类型、六维分值、TOP3 方向名称，不发送姓名/性别/行业/订单。
- 环境变量：`AI_API_KEY`、`AI_BASE_URL`（默认 OpenAI）、`AI_MODEL`（默认 `gpt-4o-mini`）。
- 未配置或调用失败时，前端保留本地模板摘要，报告功能不受影响。

## 六、业务埋点（GTM）

容器已接入；业务事件通过 `window.dataLayer.push({ event, ... })` 上报：

| 事件 | 触发 |
|---|---|
| `quiz_start` / `quiz_complete` / `quiz_restart` | 开始 / 完成 / 重测 |
| `result_view` | 结果页渲染 |
| `report_teaser_expand` | 展开深度报告预告 |
| `unlock_click` | 点击解锁 |
| `order_request` / `order_created` / `order_fail` | 下单 |
| `pay_success` | 验单成功 |
| `report_open` | 打开深度报告 |
| `ai_summary_ok` | AI 摘要成功 |
| `report_card_open` | 生成报告分享卡 |
| `poster_open` / `image_save` / `poster_share` | 海报相关 |
| `wechat_block` | 微信内被拦截提示 |
| `referral_visit` / `invite_share` / `invite_claimed` / `invite_unlock` | 邀请裂变 |

## 八、环境变量清单

| 变量 | 必填 | 说明 |
|---|---|---|
| `ALIPAY_APP_ID` | 是 | 生产应用 APPID |
| `ALIPAY_PRIVATE_KEY` | 是 | 应用私钥（PKCS8 原文，支持含 `\n`） |
| `ALIPAY_PUBLIC_KEY` | 是 | 支付宝公钥 |
| `ALIPAY_SITE_URL` | 是 | `https://www.career-turn.icu` |
| `ALIPAY_PRICE` | 否 | 默认 9.90 |
| `ALIPAY_SELLER_ID` | 否 | 2088 开头 PID，用于验单二次校验 |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | 否 | 开启邀请裂变 |
| `AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL` | 否 | 开启 AI 摘要 |
