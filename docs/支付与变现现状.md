# 支付与变现现状（2026-11-25）

> 本文是当前实际实施的方案。历史文档 [支付宝 AI 付 / Vibe Pay](./支付宝AI付-VibePay接入.md) 与 [微信支付](./微信支付接入.md) 已不再对应线上实现，仅作备选方案参考。

## 一、支付通道

- 产品：**支付宝手机网站支付**（`alipay.trade.wap.pay`，`product_code=QUICK_WAP_WAY`）
- 应用与产品已签约上线，站点：`https://www.career-turn.icu`
- 价格：服务端唯一来源 `ALIPAY_PRICE`（默认 `9.90`），前端展示由 `/api/alipay/price` 获取，前端传价格无效；**设为 `0` 时免费开放**，前端直接本机解锁，下单接口返回 `FREE_MODE` 拒绝下单。
- 回调：`notify_url = {ALIPAY_SITE_URL}/api/alipay/notify`，`return_url = {ALIPAY_SITE_URL}/api/alipay/return`
- 微信内置浏览器无法唤起支付宝，前端会提示“在浏览器打开”。

## 二、订单与解锁（无状态设计）

Vercel Serverless 多实例不共享内存，因此**不持久化订单**，以支付宝侧订单为唯一权威：

1. `POST /api/alipay/create-order` → 生成 `outTradeNo`，返回签名后的收银台 URL；同时下发 `rb_order` Cookie（15 分钟、`SameSite=Lax`）作为订单号兜底。
2. 用户支付完成 → 支付宝 302 到 `/api/alipay/return` → 再 302 回 `/?pay_return=1&out_trade_no=...`；中途退出走 `quit_url`，同一入口 `?quit=1` → `/?pay_cancel=1`。
3. 前端调 `POST /api/alipay/verify` → 服务端 `alipay.trade.query` 主动查单，校验金额/卖家/订单号。
4. 支付成功 → 服务端签发 HMAC 解锁令牌（1 年）→ 前端存 localStorage → 打开深度报告。
5. 若回跳失败或用户提前关页，再点一次解锁会先核上一笔订单（30 分钟内），避免重复付款。
6. Safari 兜底：回跳无参数（原标签恢复）或 `localStorage` 被清时，页面加载/切回前台会读取 `rb_order` Cookie 静默核单；已付款但本机结果丢失时明确提示重测（购买凭证仍在，重测后直接可看报告）。

`/api/alipay/notify` 仅做验签 + 订单号格式 + 金额校验，作为日志与兜底；业务解锁不依赖它。

## 三、深度报告权益

- 权益凭证：`rb_unlock = { token, exp, via }`，目前仅 `via=pay`
- 令牌由服务端私钥派生密钥签名；报告在本机生成，因此付费墙是“信用门槛”，不宣称 DRM 级防破解
- 清除浏览器数据/换设备会丢失本机凭证；可打开 `/restore.html` 凭订单号恢复（1 年内有效）
- 报告在本机根据作答数据生成，不上传服务器

## 四、邀请裂变（已下线）

2026-11 起下线“邀请好友免费解锁深度报告”：它会与付费互相打架，也容易触发微信诱导分享规则。`/api/invite/state` 与 `/api/invite/claim` 现在返回 410，前端不再展示邀请入口。若要恢复，请改成“邀请解锁双人对比/资料包”等独立权益，不要送同一份付费报告。

## 五、AI 个性化摘要（可选）

- `POST /api/ai-summary`，只发送人格类型、六维分值、TOP3 方向名称，不发送姓名/性别/行业/订单。
- 环境变量：`AI_API_KEY`、`AI_BASE_URL`（默认 DeepSeek）、`AI_MODEL`（默认 `deepseek-flash`）。
- 未配置或调用失败时，前端保留本地模板摘要，报告功能不受影响。

### DeepSeek 配置示例（2026-11 官方文档）

| 变量 | 值 |
|---|---|
| `AI_API_KEY` | DeepSeek 开放平台创建的 API Key（`sk-...`） |
| `AI_BASE_URL` | `https://api.deepseek.com`（官方 quick start 用法；代码会拼 `/chat/completions`） |
| `AI_MODEL` | `deepseek-flash`（推荐，V4.1-Flash）；更高质量可用 `deepseek-v4-pro` |

说明：
- 接口为标准 OpenAI Chat Completions：`POST https://api.deepseek.com/chat/completions`，认证 `Authorization: Bearer {AI_API_KEY}`。
- 当前官方模型只有 `deepseek-flash` 与 `deepseek-v4-pro`；旧的 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 退役。
- 官方文档写明**思考模式默认开启**（effort 默认 high）。本代码在识别到 `deepseek.com` 时会显式传 `thinking: { type: "disabled" }`，避免推理 token 占满 `max_tokens`、保证摘要稳定返回。
- 非思考模式下 `temperature` 正常生效；摘要请求 `max_tokens=420`、超时 15 秒。
- 价格（官方 2026-11 定价，deepseek-flash）：输入缓存未命中 1 元/百万 tokens（高峰 2 元），输出 4 元/百万 tokens（高峰 8 元）。一条约 300 tokens 的摘要成本低于 0.01 元。
- 官方文档：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/

| `ALIPAY_APP_ID` | 是 | 生产应用 APPID |
